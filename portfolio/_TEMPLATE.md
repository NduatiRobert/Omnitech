HOW TO ADD A PROJECT
1. Copy this file and rename the copy, e.g. 2026-10-abc-supermarket-cctv.md
   (the part after the date becomes the web address: abc-supermarket-cctv.html)
2. Upload the photos to portfolio/images/ (phone photos are fine; they are resized automatically).
3. Fill in the details between the --- lines:
   - client: the client's name, or e.g. "Private residence" / "Confidential client"
     (always get the client's permission before naming them or showing their premises)
   - date: year and month the project was completed, e.g. 2026-10
   - service: one or more of cctv-installation, internet-installation, hotspot-business,
     website-development, software-development, digital-marketing, business-automation,
     zoho-consulting (separate with commas)
   - highlights: short facts separated by commas, shown as tags
   - cover: the main photo. Leave empty to use a branded graphic.
   - gallery: more photos, separated by commas (optional)
   - featured: true shows the project first
4. Delete the draft: true line to publish, then save / commit. The site rebuilds automatically.

Suggested structure for the write-up:

## The challenge

What the client needed and why.

## What we did

The solution: equipment, setup and how we delivered it.

## The result

What changed for the client. A short quote from the client works well here.

> "Now I can see all my branches from my phone." (Client name, role)
